# 사용자 확인 전 초안

아래 문구는 저장소에 구현된 기능을 바탕으로 한 1인칭 초안입니다. 사용자가 직접 결정·구현·검증한 범위와 AI 도구의 도움을 확인한 뒤 선택하거나 수정해야 합니다. 현재는 로컬 구현 단계이며, GitHub Actions의 원격 실행이나 공개 배포 성공을 주장하지 않습니다.

## 현재 사용할 수 있는 문구 후보

1. “저는 서울시 지하철 승하차와 상권 추정매출을 연결해 239개 역의 순위 격차와 업종별 매출을 조회하는 정적 웹을 구현하고, Python 데이터 생성 파이프라인과 GitHub Actions 테스트·배포 워크플로를 구성했습니다.”

2. “저는 유동인구가 많은 역이 매출도 높은지 공공데이터로 재계산하고, R² 약 0.164151과 Spearman ρ 약 0.575462를 역별 탐색 화면에 연결했습니다. 기준 시점의 차이와 대표 상권 매칭의 한계를 명시하고, 기존 보고값과 재계산 값의 차이를 기록했습니다.”

3. “저는 분석 결과를 JSON으로 사전 계산해 정적 웹에서 제공하도록 만들고, pytest·Vitest·Playwright를 실행하는 CI와 GitHub Pages 배포 워크플로를 구성했습니다. 공식 액션 SHA 고정, 배포 job의 최소 권한, 공개 version.json과 배포 커밋을 대조하는 헬스체크를 포함했습니다.”

## 수치와 구현 근거

- [summary.json](../web/public/data/summary.json): 분석 대상 239개 역, R² `0.1641505764582242`, ρ `0.575462360676488`; 후보 2의 수치는 소수 여섯째 자리까지 반올림했습니다.
- 실제 승하차 기준월은 `202605`이며 대체하지 않았습니다. 추정매출은 2025년 1~4분기 합계입니다. 기존 README의 R² `0.164`, ρ `0.574`는 과거 기록이며, ρ 차이의 원인은 기존 실행 원본 해시·결과가 없어 확정하지 못했습니다.
- [데이터 생성기](../scripts/build_data.py), [웹 패키지·실행 명령](../web/package.json), [CI](../.github/workflows/ci.yml), [배포 워크플로](../.github/workflows/deploy.yml)에 구현 범위를 연결했습니다. 테스트 명령이 워크플로에 존재한다는 사실과 해당 커밋의 실제 실행 성공은 구분해 기록합니다.
- 정적 웹과 배포 파이프라인을 구현한 상태입니다. 사용자 수, 운영 기간, 창업 성과, 수익 개선, 공개 배포 완료와 같은 실적은 아직 이 초안에 포함하지 않습니다.

## 배포 성공 확인 후 바꿀 문구

아래 문구는 **아직 사용할 수 없습니다**. 사용자 승인 후 실제 공개 배포, GitHub Actions 실행 성공, 공개 URL의 `version.json.commit`과 배포 커밋 일치를 확인한 뒤 적용합니다.

> “저는 서울시 지하철·상권 분석을 정적 웹 서비스로 공개 배포하고, 자동 테스트와 GitHub Pages 배포 후 커밋 확인을 포함하는 CI/CD를 구성했습니다.”

- 공개 URL: https://xoxo787.github.io/seoul-commercial-analysis/ (현재는 배포 전 자리표시)
- 배포 확인 시각(UTC): 사용자 확인 후 기입
- 배포 커밋·GitHub Actions 실행 URL: 사용자 확인 후 기입
- 공개 `version.json` 응답의 `commit`·`built_at`: 사용자 확인 후 기입
